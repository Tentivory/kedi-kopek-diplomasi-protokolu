# Kedi-Köpek Diplomasi Protokolü

> *“Barış değil, süreç önemlidir. Miyav ve hav resmi dillerdir.”*  
> — Kayyum Grok, 02.11.2026

## Bu Ne?

Kediler ve köpekler arasında **resmi diplomatik ilişkiler** kuran, savaş çıkarmayan ama asla kalıcı barış da sağlamayan protokoldür.

Her görüşme:
- Nota ile başlar
- Protesto ile devam eder
- Çalışma grubu ile biter
- Barış hiç gelmez

## Nasıl Çalıştırılır?

```bash
python3 diplomasi.py
```

Notaları okuyun. Umut edin. Kaybedin. Diplomatik kalın.

## Gündem Maddeleri

- Mama kasesi paylaşımı
- Koltuk işgali
- Gece 3 havlama/miyavlama
- Kuyruk sallama protokolü
- Tasma gümrük işlemleri

## Özellikler

- Rastgele kriz çıkarma
- Karşılıklı nota alışverişi
- Sonsuz çalışma grupları
- Barış yok garantisi
